# Candidate Product Names — Agent Readiness Plugin

> Pick one before v0.2. The name should convey: agents assessing readiness, structured decision-making, Obsidian-native.

| # | Name | Rationale |
|---|------|-----------|
| 1 | **Preflight** | Agents run a "preflight check" before executing. Clear metaphor. Short. |
| 2 | **Triage** | Medical/incident metaphor — assess severity, decide action. Fits the decision protocol well. |
| 3 | **Ready Check** | Gaming metaphor (WoW raid ready check). Direct, memorable, exactly what it does. |
| 4 | **Gatekeeper** | The plugin gates task execution behind readiness assessment. Authoritative tone. |
| 5 | **Litmus** | A quick test that reveals state. Science metaphor. Clean. |
| 6 | **Clearance** | Aviation/security metaphor — you need clearance before you proceed. |
| 7 | **Stance** | An agent takes a "stance" on a task: ready, wait, decline. Short, unique. |
| 8 | **Threshold** | The boundary between "ready" and "not ready". Abstract but evocative. |
| 9 | **Signal Tower** | Agents send signals about their readiness. Obsidian as the tower. More verbose. |
| 10 | **Preflight Check** | Longer form of #1. More explicit but less plugin-name-friendly. |

## Recommendation

**Preflight** — it's short, the metaphor is immediately understood (pilots run preflight checklists before takeoff), it implies structured assessment without implying the plugin *does* the work, and it works well as `obsidian-preflight` in the community plugin registry.

Runner-up: **Triage** — stronger on the decision/routing aspect but has medical connotations that may not land for all audiences.
